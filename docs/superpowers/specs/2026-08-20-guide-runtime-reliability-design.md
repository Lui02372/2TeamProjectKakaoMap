# 부산여행 가이드 실행 오류 수정 설계

## 목표

대화 질문이 500으로 실패하는 문제와 사이드바 위젯 글자가 보이지 않는 문제를 수정한다. Kakao 지도·로컬 API는 사용자가 활성화했으며 실제 키워드 검색이 200으로 응답하는 것을 확인했다.

## 원인

- Supabase 대화방 및 메시지 INSERT 응답에는 내부 관계 필드가 포함되지만 `ChatThread`와 `ChatMessage`는 추가 필드를 금지한다. 저장 후 응답 검증이 실패해 500이 발생한다.
- 사이드바의 모든 하위 요소에 흰색을 적용하는 CSS가 흰 배경의 버튼과 선택 상자에도 적용된다.
- 회원가입 비밀번호 최소 길이 8자가 교육용 예시 비밀번호 `pw01`과 충돌한다.

## 설계

- 대화 저장소는 Supabase 행에서 응답 모델이 선언한 필드만 투영한 후 검증한다.
- 사이드바의 일반 텍스트만 밝게 유지하고 버튼 및 선택 상자 내부 텍스트는 진한 남색으로 명시한다.
- 회원가입 최소 비밀번호 길이를 4자로 낮추고 화면 안내도 4자로 맞춘다. Argon2id 해시는 유지한다.
- `id01 / pw01`, `id02 / pw02`를 반복 실행 가능하게 등록하는 Supabase SQL을 제공한다.

## 검증

- 추가 필드가 포함된 Supabase 행으로 대화방과 메시지 모델 생성 회귀 테스트
- 프론트엔드 CSS 선택자 및 비밀번호 안내 회귀 테스트
- 4자 회원가입 허용 및 3자 거부 테스트
- 전체 백엔드·프론트엔드 테스트와 실제 Kakao 검색 호출
